# 🧠 Inteligencia Artificial - UTN

Repositorio personal donde documento mi aprendizaje en la materia **Inteligencia Artificial** de la carrera Ingeniería en Sistemas de Información (UTN FRC).

La idea de este repositorio no es solo cumplir con los trabajos prácticos, sino también construir un **portfolio técnico** que refleje cómo pienso, cómo resuelvo problemas y cómo evoluciono a lo largo de la cursada.

---

## 📚 Contenido

El repositorio está organizado por unidades temáticas:

```
IA/
├── Unidad_1/  → Introducción a la IA
├── Unidad_2/  → Agentes Inteligentes
├── Unidad_3/  → Búsqueda y resolución de problemas
├── ...
```

En cada unidad se incluyen notebooks de Jupyter con:

* Resolución de ejercicios
* Explicaciones teóricas en lenguaje propio
* Implementaciones en Python (cuando aplica)
* Conclusiones y análisis

---

## 🛠️ Tecnologías utilizadas

* Python 🐍
* Jupyter Notebook / JupyterLab
* Git & GitHub

---

## 🎯 Objetivo

* Afianzar los conceptos teóricos de la materia mediante la práctica
* Desarrollar habilidades de resolución de problemas
* Documentar el proceso de aprendizaje de forma clara y ordenada
* Construir un repositorio que pueda ser utilizado como material de estudio y portfolio profesional

---

## 📌 Sobre la metodología

Cada notebook sigue una estructura similar:

1. Enunciado del ejercicio
2. Desarrollo / resolución
3. Código (si aplica)
4. Explicación del resultado
5. Conclusión personal

La idea es priorizar la comprensión por sobre la simple resolución.
